# AI 운용관리 (regime-council)

주식·채권·환 AI 에이전트가 **자산별 MP(모델 포트폴리오)를 산출**하고,
**투자 포인트마다 손실한도·과거 사례·펀더멘탈·MP 괴리를 점검**해 조정안을 내며,
**매일 전 포지션의 한도 소진율·손절 신호를 점검**해 경고하고 로그·투자위 보고서를 만든다.
최종 판단과 실행은 운용역, 확인은 독립 점검 기능, 한도 확정은 투자위원회.

**원칙**: 한도·소진율·스트레스·괴리·과거 유사 국면은 **코드가 결정적으로 계산**(CODE)하고,
에이전트(Claude)는 **해석·조정안·브리프**만 쓴다(AGENT). 리스크 등급은 코드 하한 아래로 내릴 수 없다.
지금은 Claude 단독 — 교차검증 자리는 **산출자 + 독립 검증자 2패스**(동일 입력, 서로 못 봄)를 코드가 비교해
일치/부분 불일치/불일치로 판정한다. ChatGPT 슬롯은 "미연결"로 비워 뒀다.

## 웹 공유본 (보기 전용)

**https://zmdkdzm1-collab.github.io/regime-council/** — 설치 없이 링크로 보는 화면. 만든 시점 숫자로 고정된 정적 사이트(GitHub Pages, main 브랜치 `docs/`)다.
모든 탭·차트·상세가 열리고, 백테스트는 전략별 기본 설정 × 최근 기간(1·3·5·10년·올해·전체)과 기간별 전체 비교를 미리 계산해 넣었다.
점검 실행·저장·대화처럼 서버가 필요한 버튼은 '원본 앱에서 실행' 안내만 한다. 갱신: 서버를 켠 채 `python share_site.py` → 커밋·푸시(1분 안에 반영).

## 설치·실행

```
pip install -r requirements.txt
setx ANTHROPIC_API_KEY "sk-ant-..."      # (선택) console.anthropic.com 발급, 새 터미널부터 적용
python web.py                            # → http://127.0.0.1:5101
```

저장소에 마지막 계산 데이터(`data/` — 가상 시험 포트, 공개 시세, 인포맥스 마지막 값)가 들어 있어 **받자마자 같은 화면이 뜬다.**
주식·밸류에이션·백테스트는 공개 데이터라 어느 PC 에서나 '다시 받기'로 새로 받아진다. 인포맥스 실시간은 인포맥스가 깔린 PC 에서만 갱신되고,
없으면 저장된 마지막 값을 보여 준다. 과거 시계열을 처음부터 다시 받으려면 `python fetch_history.py`.

**평소에는 `대시보드_열기.bat` 을 더블클릭** — 서버를 자기 창에서 켜고 브라우저를 연다(이미 켜져 있으면 브라우저만).
그 창을 닫으면 서버가 꺼진다. Claude 앱의 미리보기 창에서 띄운 서버는 앱이 그 창을 닫을 때 같이 멈추므로 평소 사용에는 쓰지 않는다.

API 키가 없어도 **CODE 부분(한도·신호·스트레스·괴리·과거 사례·로그·월간 보고서)은 전부 동작**한다.
키가 있으면 MP 산출, 점검 보고서 해석·조정안, 일일 브리프, 채팅, 국면 토의가 켜진다.

## 화면 (탭)

> **메뉴는 왼쪽 사이드바**(오늘 · 포트 · 관리 · 시장으로 묶음, 좁은 화면에서는 ☰ 서랍).
> **대화는 오른쪽 아래 풍선 → 오른쪽 전체 높이 패널**(`Ctrl`+`/` 로 여닫기). 왼쪽 가장자리를 끌거나 ⤢ 로 넓힐 수 있고 너비는 브라우저에 기억된다.
> 화면이 1,500px 이상이면 패널이 본문을 밀어 내 가리지 않고, 그보다 좁으면 본문 위에 뜬다.
> 모든 탭에서 열 수 있는 챗봇 창(모두/BOND/STOCK/FX 선택, 빠른 질문, 셋이 토의, 오늘의 보고 다시 듣기).
> "화면 공유"가 켜져 있으면 지금 보고 있는 탭의 화면 텍스트(최대 6,000자)를 질문과 함께 보내 '이거·여기'를 그 화면 기준으로 답한다(`/api/room/talk` 의 `screen`).
> API 키가 없으면 담당 숫자 카드로 답한다.
>
> 대시보드는 반드시 서버 주소(`http://127.0.0.1:5101`)로 연다. `static/index.html` 파일을 직접 열면 서버가 없어 "서버 응답 없음"이 뜨고 모든 버튼이 동작하지 않는다.

| 탭 | 내용 | 출처 |
|---|---|---|
| **에이전트 룸** (첫 화면) | 채권·주식·환 담당자 3명이 **1인칭으로 오늘의 보고**(담당 포트 상태·걱정·제안 행동 버튼·운용역에게 묻는 말) → 대화 스트림(전체 또는 특정 담당자에게 질문, 답변에 행동 버튼) → "셋이 토의시키기"(라운드별 발언이 대화로 표시) → 관리 현황(담당 포지션·경고·보류 보고서·MP) | AGENT (키 없으면 코드가 같은 수치로 1인칭 대사 생성) |
| **대시보드** | 손실한도 소진율 게이지(전체·채권·주식·환, 경고/축소/중단 임계선) → 발동 신호 카드(조치 입력) → MP 괴리 상위 → 오늘 할 일 → 일일 브리프·스트레스·데이터 검증 | CODE (+브리프 AGENT) |
| **점검 보고서** | 투자 포인트(신규 투자 / 6개월 비중 조절 / 손실한도 접근 / 시장 급변) 선택·입력 → 실행 → 4항목 보고서 + 조정안 + 산출자/검증자/ChatGPT 3슬롯 + 의사결정 규칙 + 채택/수정/기각/보류 | CODE + AGENT |
| **MP·괴리** | 자산별 MP 산출(2패스)·채택·이력, 현 포트 vs 채택 MP 괴리(표+발산 막대), 과거 유사 국면 표 | AGENT + CODE |
| **한도·로그** | 한도 트리(전체→자산→포지션 손절선), 스트레스 6개 시나리오, 한도표(가안) 메타, 경고 레지스트리(경고→조치→확인→종결), 로그(해시 체인 무결성) | CODE |
| **투자위 보고서** | 월 선택 → 경고 건수·대응시간·소진율 추이·점검 보고서 목록·채택률·미결·버전 이력 | CODE 집계 |
| **참고** | 매크로 패널, 에이전트 채팅(자동 라우팅/지목), 국면 토의 실행, 모든 산출물 열람 | — |

헤더의 **일일 점검 실행**이 상시 점검(소진율·손절·스트레스·시장 급변 감지 → 경고 레지스트리 동기화 → 브리프 → 각 에이전트의 오늘의 보고 → 로그·보고서)이다.
에이전트 이름·역할·말투는 `config.py` 의 `AGENT_PERSONAS` 에서 바꾼다. 에이전트가 제안하는 행동(점검·MP·토의)은 버튼 한 번으로 백그라운드 실행되고, 끝나면 그 에이전트가 결과를 대화로 알려준다.

**자동 실행(스케줄러)**: 서버가 떠 있는 상태에서 별도 프로세스로 `daily.run_daily()` 를 돌리면 로그·레지스트리 파일을 두 프로세스가 동시에 쓸 수 있다.
작업 스케줄러에는 서버의 API 를 호출하게 등록한다:
```
powershell -Command "Invoke-RestMethod -Method Post -Uri http://127.0.0.1:5101/api/daily/run -Headers @{Origin='http://127.0.0.1:5101'}"
```
(서버를 띄우지 않는 PC 라면 `python main.py daily` 단독 실행은 괜찮다.)
Windows 작업 스케줄러로 매일 아침 `python -c "import daily; daily.run_daily()"` 를 걸어두면 자동화된다.

## 시장 전반 분석 — BOND·STOCK·FX

| 이름 | 데스크 | 그림 | 모양 |
|---|---|---|---|
| **BOND** | 채권 | `static/avatars/bond.svg` | 파랑·시안 구슬 + 수익률 곡선 |
| **STOCK** | 주식 | `static/avatars/stock.svg` | 초록·민트 구슬 + 상승 추세선 |
| **FX** | 환 | `static/avatars/fx.svg` | 보라·핑크 구슬 + 순환 화살표 |

이름·데스크·그림은 `config.AGENT_PERSONAS` 에서 바꾼다(내부 키 bond/equity/fx 는 데이터·파일명에 쓰이므로 그대로).
화면 스타일은 애플풍(흰 단색 카드·넓은 여백·큰 제목·macOS 컨트롤 — 세그먼트, 회색 팝업 선택 칸, 설정 앱식 묶음 행, 색 칸 없는 큰 숫자 줄) + AI 글로우 + 한화 오렌지 포인트. 오렌지는 브랜드 전용(주 버튼·링크·포커스·내 말풍선·로고 링)이라
에이전트 색에 쓰지 않는다. 값은 `static/index.html` 의 `--brand` 변수(근사값 #F37321) — 정식 CI 값이 있으면 거기만 바꾼다.
한화 로고(트라이서클)는 그려 넣지 않았다 — 쓰려면 브랜드 가이드가 허용하는 공식 파일을 `static/` 에 두고 `.logo` 자리에 넣는다.
같은 세 에이전트가 운용관리(MP·점검·한도)뿐 아니라 **국내·글로벌 시장 전반 + 우리 포트** 질문에 답한다.
프롬프트(`prompts/common.md`·`bond.md`·`equity.md`·`fx.md`)와 계산 모듈(`analytics.py`)은 하나이고, 실행 형태가 둘이다.

| 형태 | 어디서 | API 키 | 용도 |
|---|---|---|---|
| **대화형 데스크** | Claude Code (`헤지펀드` 폴더에서 세션 시작) | 불필요 | 자유 질문, 즉석 계산, 웹 검색 보완, 대화형 시장 브리프 |
| **자동 리포트** | `python main.py brief [--fetch]` | 있으면 데스크 3곳+CIO 종합, 없으면 CODE 지표만 | 매일 아침 브리프 |

- 대화형 데스크 파일: `헤지펀드/.claude/agents/{bond,stock,fx}.md`(서브에이전트 — 시작 시 위 프롬프트를 읽고 analytics 를 실행),
  `헤지펀드/.claude/skills/market-desk/SKILL.md`(메인 세션이 데이터 갱신 → 질문 분배 → 교차 확인 → 종합 → 브리프 저장).
  새 세션부터 인식된다. 예: "오늘 시장 어때?", "FX 한테 환오픈 늘려도 되는지 물어봐", "시장 브리프 만들어줘".
- 브리프 형식은 `prompts/market_brief.md`(데스크 섹션 A + CIO 종합 B) — 두 형태가 같은 형식을 쓴다.
  산출물: `reports/YYYY-MM-DD_시장브리프.md`(에이전트 포함) / `reports/YYYY-MM-DD_시장지표.md`(CODE 전용).
- API 경로의 모든 에이전트 호출(MP·점검·룸·토의 포함)은 공통 컨텍스트에 `analytics.to_markdown("all")` 을 받는다.

```
python analytics.py status                 # 데이터 기준일·갱신 필요 여부
python analytics.py bond|equity|fx|cross|all [--json]
python analytics.py calc carry --tenor 5   # 즉석 계산: carry · hedge-cost · hedged-yield · fx-shock · bond-pnl · erp
```

## 멀티에셋 유니버스 · 주식 대시보드 (universe/ · equity.py)

**유니버스 문서(예시)를 데이터로** — 사진으로 받은 '멀티에셋 투자 유니버스 — 자산·파생상품·결합 전략'을 워터마크 없이 옮겼다.
- `universe/universe.json` — 원본 데이터: 기초자산 30개 항목(채권·주식·외환·원자재·대체) · 파생상품 30개(Future·Swap·TRS·Option·
  Structured·Credit) · 결합 전략 67개(구조·수익 시나리오·손익 형태·주요 리스크, 3~6개월 시계) · 손글씨 메모.
- `universe/멀티에셋_유니버스_전략.xlsx` — 위 데이터의 엑셀본(개요·기초자산·파생상품·결합전략·주식 시트). `python universe.py` 로 다시 만든다.
- `universe/equity.json` — 주식 항목별 데이터 연결(티커 36개)과 결합 전략 17개의 백테스트 준비 상태(바로 가능 4 · 근사 11 · 데이터 필요 2).

**주식 탭**(사이드바 시장 → 주식) — 사용자 담당 범위(주식)부터:
- 시장 대시보드: 쉬운 말 결론(오르는/내리는 지역·변동성) → 지역별 표(국내·선진국·신흥국: 1주·1개월·3개월·올해·1년 고점 대비·흐름) →
  스타일·팩터 / 섹터·테마(시장 대비 3개월, 막대) → 변동성(VIX·VXN·KOSPI200 실제 흔들림, 옵션 보험료 수준) → 우선주(삼성 우선/보통 가격비 1년 위치).

## 백테스트 (backtest.py — 사이드바 '내 담당 → 백테스트')

유니버스 문서의 주식 결합 전략을 **고르기 → (필요하면 설정) → 실행** 세 단계로 돌린다. 화면은 macOS 설정 앱 모양 — 왼쪽 전략 목록, 오른쪽에 설정 묶음 · 기간 묶음(최근 세그먼트 · 과거 국면 팝업 목록 · 날짜) · 실행 · 결과(좁은 화면에서는 목록 대신 맨 위 선택 칸). 설정을 안 바꿔도 기본값으로 바로 돈다(1~2초).
- 돌릴 수 있는 전략 14개: 전술적 Long/Short · 지역 간 상대 뷰 · 변동성 타겟팅 · 지수 TRS · 팩터 바스켓 TRS · 방어형 QIS(규칙 직접 계산) ·
  보호적 풋 · 칼라 · 풋 스프레드 칼라 · 커버드콜 · 주식 대체 · 콜 스프레드 · ELB(원금보장형) · CPPI. 회색 3개(이벤트 헤지·VIX 콜·쿠폰형 ELS)는 데이터·조건 가정이 더 필요.
- 결과: 쉬운 말 결론('그냥 보유' 대비) · 연 수익률 · 최대 낙폭 · 흔들림 · 샤프 · 누적 곡선 · 낙폭 곡선 · 연도별 · 시장이 3% 넘게 빠진 달의 평균.
- 기간: 최근(1·3·5·10년·올해·전체) 버튼 · **과거 국면 55개**(검색·분류·스크롤 목록) · 시작·종료일 직접 지정. 과거 국면은 `universe/regimes.json`(사건 40개: 한국 2026 · 한국 증시 · 글로벌 위기·급락 · 금리·정책 · 반도체·AI — 날짜는 가격 데이터와 대조, 2026년은 기사 확인) + 가격으로 찾은 KOSPI·S&P500 큰 급락·급등 15개. 줄을 추가하면 화면에 바로 나온다. 사건일은 결과 그래프에 세로선, 1.5년 안쪽은 일 단위 그래프·2년 안쪽은 월별 표. 버튼을 누르면 날짜 칸이 채워진다. 1년 남짓보다 짧으면 연율로 늘리지 않고 기간 수익률로 보여 준다. 한국 지수 전략은 2012년부터.
- 위쪽 **[돌려보기 | 전체 비교]** 중 **전체 비교** 탭: 기간 버튼(1·3·5·10년·올해·전체, 돌려보기에서 국면·날짜를 골라 두었으면 그 기간도)을 누르면 모든 전략을 기본 설정으로 계산 → '전략별 기대수익과 리스크' 표(`data/backtest_summary.json`) — 주식 탭 전략 표와 STOCK 에이전트 컨텍스트에도 들어간다.
  주식 탭 전략 표의 **돌려보기** 버튼은 그 전략을 골라 둔 채 백테스트 화면으로 간다.
- 가정: 선물 = 지수 총수익 − 현금(완전 담보), 롤 비용 연 0.3%p, 노출 변경 0.05% · 현금 = 미국 13주 국채(^IRX), 한국 국고3년 − 0.3%p(2012년~, CD 이력 없어 대용) ·
  옵션 = 블랙숄즈(S&P500 = VIX, 나스닥100 = VXN, KOSPI200 = 실제 변동성 × VIX/S&P 실제 변동성) + 스큐 근사 + 거래비용(명목 0.02% + 프리미엄 3%), 매월 1개월물.
  총수익: S&P500 = SPY, KOSPI200 = KODEX 200, 나머지 지수 = 가격 + 배당수익률 가정. API `GET /api/backtest/catalog`, `POST /api/backtest/run`, `POST /api/backtest/all`.
- 과거 결과는 미래를 보장하지 않는다. 특히 옵션 전략은 실제 호가·스큐와 다를 수 있다.

## 전략 보드 (strategy.py — "지금 무엇을 해야 하나")

포지션·한도·정량 결과를 규칙으로 판단해 **할 일**과 **실행 수량**을 보여 준다(CODE — 에이전트는 설명·반론만).

- **지금 할 일**: 포지션마다 손절 · 축소 · 익절 · 규모 조정 · 일부 익절 · 논리 점검 · 확대 검토 · 유지 중 하나.
  같은 할 일이면 포트 위험 기여 순. 행을 누르면 다리별 수량(주·계약), 실행 주의, 숫자 근거, 엑셀의 투자 논리·반증 조건.
- **규모 조정**: 손절폭이 한 달 변동성(1σ)의 75%보다 좁으면 잡음에도 걸리기 쉽다 → 손절 금액은 그대로 두고
  손절폭을 1σ 로 넓히며 규모를 줄인다(손절 예산은 그대로).
- **논리 점검**: 기술 점수 ≤ −30 이고 한 달 안 손절 먼저 확률 ≥ 50%, 또는 정량 스캐너의 강한 신호가 보유 방향과 반대(페어 제외).
- **포트 전체**: 6개월 한도 초과 확률(변동성/국면), 초과 확률 20%를 위한 권고 노출(quant `scale_for_breach`),
  위험 상위 3, 손절 예산 사용률, 최악 스트레스, 같은 종목이 여러 포지션에 걸린 집중도.
- **전략별 카드**: 마켓타이밍 · 상대가치 · 이벤트 드리븐 · 자금기반 · 위탁 대용 · 환 오버레이 — 배분(목표 대비), 위험 기여,
  손익, 운용 원칙(진입·규모·청산), 지금 상태.
- **새 기회**: 스캐너 기술 점수 ±30 이상 → 맞는 전략·실행 수단, 지금 보유와의 방향, 손절 예산 여유.
- 화면 순서(10-21 개편 — 쉬운 말): 결론 한 줄 → 숫자 4개(손실한도 넘을 가능성·위험 쏠림·주식 여유·급락 충격) → 해야 할 일 묶음(줄이기·다시 확인하기·이익 챙기기·늘려 볼 만한 것·그대로 두기, 줄을 누르면 주문 수량·근거·투자 논리) → 시장 기회·전략별 표. 문장은 strategy.py 가 만든다(`verdict`·`groups`·`do`·`why`·`tiles`·`say`).
- 화면: **전략** 탭. `python strategy.py`, `/api/strategy`(요청마다 다시 판단), 일일 점검 때 `data/strategy.json` 갱신,
  에이전트 컨텍스트에 포함. 포지션의 투자 논리·반증 조건·근거는 시험 포트 엑셀 '포지션' 시트 O~Q 열(book.py 가 옮김).
- 매매 지시가 아니라 점검 제안이다. 수량은 지금 시가 기준이며 거래비용·체결 영향·대차 가능 여부는 반영하지 않는다.

## 정량 분석 (quant.py — 모닝미팅 '정량투자 AI 활용')

"투자 포트폴리오 및 기회 정량분석 → 기술적 매력도, 현 포지션의 과거 변동성·국면 고려 예상손익"을 코드로 계산한다(에이전트는 해석만).

- **기술적 매력도**(−100~+100): 포지션 NAV(다리 수익률을 시가 비중으로 합성 — 페어·선물 헤지 포함)의 추세(MA200 대비)·6개월/1개월 모멘텀(변동성 대비)·RSI14 역방향. 관례적 휴리스틱.
- **예상손익(1·6개월)**: ① 변동성 기준(EWMA λ=0.94, 추세 없음, 4,000 경로) ② 국면 기준(포지션 상태+VIX 가 비슷한 과거 25개 날짜의 실제 이후 경로). 분위수와 손절·목표 중 먼저 닿을 확률.
- **포트**: 같은 날짜 경로로 합산(상관 반영) → 6개월 분포, 기간 중 손실한도 초과 확률, 위험 기여.
- **기회 스캐너**: 지수·환율·원자재·금리(가격 환산)의 기술 점수와 국면 기준 6개월 중앙값·상승 비율.
- 화면: **정량** 탭(포트 분포·포지션별 막대·스캐너, 행을 누르면 세부). `python quant.py`, `/api/quant`, 일일 점검 때 자동 갱신, 일별 스냅샷 `data/quant/YYYY-MM-DD.json`(DB 적재용).
- 가격 이력: `data/history/legs_daily.csv`(yfinance 전체 이력·증분). 대용: KOSPI200 선물=KODEX 200, 10년 국채선물=국고10y×듀레이션, 달러·엔선물=현물환.

## 인포맥스 실시간 (매크로 2단계)

인포맥스 엑셀 애드인 함수는 엑셀 안에서만 돌기 때문에 **브리지 엑셀**을 거친다.

1. `python infomax_bridge.py build` → `data/인포맥스_브리지.xlsx`
   - **변수** 시트: 한 줄 = 지표 하나(키·이름·담당·주제·구분·코드·항목 → `IMDP` 값·일자·상태). 행을 추가하면 끝.
   - **캘린더** 시트: `IMDT("경제지표","CALENDAR",…)` 발표 일정 — 인포맥스 '조회' 버튼으로 채우는 방식이라 자동으로는 안 받아진다(화면에서 카드 숨김).
   - **검증** 시트: 구분별 대표 항목 시험(코드·항목 이름 확인용).
2. **파일을 열어 둘 필요 없음.** 인포맥스 프로그램(로그인)만 켜져 있으면 `python infomax_bridge.py read`
   (또는 매크로·토의 탭 — 화면을 보고 있으면 5분마다 자동, "지금 받기" 버튼)가 **보이지 않는 엑셀을 따로 띄워**
   애드인(`C:\Infomax\bin\Excel64\IMxlExcelAi64.xll`)을 올리고 브리지를 읽기 전용으로 열어 값만 받은 뒤 닫는다(약 8~10초)
   → `data/macro_live.json`.
   - 사용자의 엑셀에는 붙지 않는다(새로 뜬 PID 가 기존 엑셀이면 즉시 중단). 다른 프로그램의 파일 열기가 끼어들지 않게
     DDE 를 막았다가 닫기 전에 되돌린다. 스스로 안 닫히면 그 PID(시작 시각까지 확인)와 자식 애드인 프로세스만 정리.
   - 사용자가 마침 브리지를 열어 두었으면 그 값을 읽고, 인포맥스가 꺼져 있으면 마지막 값을 유지한다.

코드 출처(이 PC 설치본): 금리 = 민평 3사 `BONDAVG**`·`"3년이하(당일)"`(`C:\Infomax\bin\excel\시가평가_matrix_3자리.xlsx`),
환율 = `USDSP_SMBCB_EXT`(24시간)·`DOLLAR`·`EURUSD`·`US03M`, 스왑포인트 = `USD3M_SMBCB`·`USD1Y_SMBCB` 의 `중간값`(1/100원 → 원 환산,
`ini\excelrealmap.dat`), 경제지표 = `C:\Infomax\bin\code\entry.xml`, 항목 이름은 주기가 붙는다 — `현재가_월`·`DATE_월`·`전년비_월`
(`ini\경제지표.csv`). 2026-10-21 숨김 엑셀로 39개 전부 값 확인.

**라이선스**: 인포맥스 데이터를 외부 AI 로 보내도 되는지 확인 전까지 `config.SHARE_VENDOR_DATA = False` —
화면·코드 계산에만 쓰고 에이전트 컨텍스트·대화 화면 공유에서는 뺀다. 허용되면 True 로 바꾸면 스왑포인트 실측이 헤지비용 계산에도 들어간다.

## 시험 포트 (Active 5,000억, 가상)

팀 구성 전에 시스템을 써보기 위한 가상 포트. 가상 설정(Active 5,000억 = 주식 2,000억·채권 3,000억, 환 오버레이 한도 1,000억,
전략 배분 목표 30/45/25, 수익 목표 없음)에 맞춰 실존 상장 상품(국내 주식·ETF, 미국 ETF, KRX 선물)으로 2026-10-20 에 구성했다.
실제 조직·계획·보유와 무관하며 **실제 투자·매매 지시가 아니다.** 운용 구조는 `data/portfolio.json`, 체험용 한도는 전체 300억(주식 160·채권 80·환 40).

- 보유 파일: `data/시험포트.xlsx` — 요약 / 포지션(16개, 시스템 관리 단위) / 구성종목(21개 다리, 수량·진입가) / 한도(체험용 가안) / 가정·출처.
  파란 글씨가 입력값. 수량·손절·목표를 바꾸면 다음 평가부터 반영된다.
- 화면: **내 포트** 탭 — 운용 시가·누적 손익·규모 사용·손실한도 소진, BOND·STOCK·FX 별 합계(카드를 누르면 해당 담당만),

- 평가: `python book.py`(또는 `python main.py book`) → yfinance 시가로 다시 평가해 `data/positions.json` 생성.
  대시보드 **일일 점검**은 이 파일이 있으면 평가부터 자동으로 한다. `--limits` 는 엑셀 '한도' 시트로 `data/limits.json`(체험용)도 만든다.
- 대용·근사: 선물은 현물(KOSPI200·환율)·국고10y 이론가로 평가(베이시스 무시), 헤지비용·거래비용·대차 수수료·조달비용 미반영,
  환 오버레이는 `asset: "fx"` 포지션(현금 없음, 명목 = 환오픈)으로 한도 엔진에 들어간다.
- 실제 보유로 바꿀 때: 같은 양식에 실제 수량을 넣되, 외부 API 전송을 고려해 종목명 대신 버킷 이름을 쓴다.

## 한도 엔진 요점 (limits.py)

- 손실 = YTD 평가손익(환헤지 비용 차감 후). 레벨 내 순손익 상계. 소진율 = max(0, −순손익)/한도.
- 3계층을 각자 규칙으로 판정: 전체·자산별 한도는 **소진율**(50% 경고 / 75% 축소 / 100% 중단), 포지션은 **손절 접근률**(70% 경고 / 100% 도달). 포지션 손절 신호는 상위 단계로 승격되지 않고 `position_stage_max` 와 리스크 등급 하한(전체·자산별 `floor_by_asset`)에만 반영된다.
- 계층 검증: 자산별 한도 합 ≤ 전체, 자산별 손절금액 합 ≤ 자산 한도(위탁 손절은 주식·채권 양쪽에 전액 계상).
- 환 한도는 환오픈분(익스포저 × (1−헤지비율))의 환 손익에만 적용(자산 손절과 환오픈 손절은 따로 판정). 위탁 포트는 look-through 로 주식/채권 분해(손익 분리 보고 `pnl_split` 없으면 비중 추정 + 경고).
- `rate_pnl_in_scope=false`(ALM 보유분): 금리 평가손익(`pnl_rate_ytd_bn`)을 한도·손절 대상에서 빼고 스프레드 손익만 포함, 스트레스에서도 금리 충격 제외. 분리값이 없으면 전액 포함 + 데이터 경고. 범위 확정은 투자위 사항.
- 스트레스 후 소진율 = max(0, 시나리오 손실 − 현재 순손익)/한도 (이익 상계). `reference: true` 시나리오(S5)는 표시만 하고 최악·등급 판정에서 제외.
- 스트레스 S0(월 1σ 역방향)으로 축소 필요 규모·신규 추가 가능 규모를 산정(둘 다 목표 = 축소 임계 75%, 자산·전체 중 작은 쪽, 다른 자산이 이미 임계 이상이면 "추가 불가").
- 신규 포지션 pro-forma: 손익 0 가정으로 합산 후 소진율·스트레스·추가 가능 규모 재계산.

## 과거 사례 점검 (history.py)

자산별 국면 특징(채권: 국고3y 레벨·3개월 변화·3s10s·AA- 스프레드·미국채 변화 / 주식: KOSPI 3·6개월 수익률·VIX·S&P 상대 / 환: USD/KRW 1년 z·3개월 변화·DXY·한미 금리차)을
robust z(중앙값·MAD)로 표준화해 유사일 10건(최근 12개월 제외, 60일 중복 제거)을 찾고, 이후 3/6/12개월 결과 분포와 6개월 내 최대 역행폭·KOSPI MDD·VIX 최고·동시 충격 수를 표로 낸다.
표본 부족(LOW_SAMPLE)·유사도 약함(WEAK_SIMILARITY)·시계열 짧음(SHORT_HISTORY) 플래그를 붙이고, 에이전트는 "유사 국면 n건 중 m건" 형식으로만 인용한다.

## 보안·운영 주의

- 스냅샷·포지션은 Anthropic API 로 전송된다 → **집계 수준만**, 실명 금지. 외부 AI 활용의 데이터 반출·정보보안 기준은 IT·준법 협의 후 확정.
- 127.0.0.1 전용 + Origin/Host 검사. 사내 공유가 필요하면 별도 검토.
- 한도표·손절선·축소 기한은 **가안** — 운용 개시 전 투자위 확정값으로 `limits.json` 교체.
- `reports/`·`data/log/` 에는 포지션 수치가 들어간다. 공유 시 범위 확인.
- 모든 산출물에 모델 ID·프롬프트 버전(해시)·입력 해시가 찍히고, 로그는 해시 체인 + `data/log/head.json` 앵커로 꼬리 절단·재작성을 탐지한다. 환경변수 `LOG_HMAC_KEY` 를 두면 HMAC 서명으로 바뀐다.
- `data/` 아래 생성물(positions·limits·checks·log·mp·history)은 `.gitignore` 에 있어 저장소·드라이브 공유 대상이 아니다. 샘플(`*.sample.json`)만 추적된다.
