# 작업 — 모델 포트폴리오(MP) 산출 (산출자 패스)

담당 자산의 MP 를 산출한다. MP 는 "향후 6개월 기준으로 우리 포트가 가져야 할 목표 상태"다.

## 입력으로 받는 것
- 시장 스냅샷, 현재 포지션·비중·듀레이션·헤지비율 표(CODE), 손실한도 현황(CODE),
  담당 자산의 과거 유사 국면 표(CODE), 현재 유효한 MP(있으면).

## 산출 규칙
1. `targets` 는 담당 자산의 **모든 기존 포지션**에 대해 쓴다 (position_id 는 제공된 ID 그대로).
   비중은 전체 포트 대비 %. 신규 버킷 제안은 `NEW_<설명>` ID 로 별도 행.
   - 채권: weight_pct + duration 필수. 해외자산이면 hedge_pct 도.
   - 주식: weight_pct 필수.
   - 환: hedge_pct 가 핵심(해외자산별), weight_pct 는 null. 환 오버레이 명목은 한도 1,000억 안에서(해외 자산은 원칙적으로 헤지 100%).
2. 현재 대비 변화가 있으면 `note` 에 방향과 이유를 한 줄로. 변화가 없으면 "유지".
3. `assumptions` 는 성장·물가·정책·신용(·환) 축별로 — 수치 가정은 `[A]`, 근거 수치는 `[F]`.
4. `rationale` 은 과거 유사 국면 표의 플래그(LOW_SAMPLE/WEAK_SIMILARITY/SHORT_HISTORY)를
   반드시 언급하고, "유사 국면 n건 중 m건" 형식으로만 인용한다. 확률·필연 표현 금지.
5. 손실한도 현황을 보고, 제안 MP 가 스트레스 시 한도를 넘기면 그 사실을 `review_triggers` 와
   `rationale` 에 적는다 (한도는 투자위 소관 — MP 가 한도를 바꿀 수 없다).
6. 목표수익률 구조(국고3y + 캐리 + 초과수익)에서 담당 자산의 기여 추정을
   `expected_contribution_pp` 에 `[E]` 로.
7. 확신도는 데이터 공백이 있으면 낮추고 `data_gaps` 에 무엇이 없는지 적는다.
