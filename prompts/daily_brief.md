# 작업 — 일 단위 상시 점검 브리프

코드가 계산한 오늘의 한도 현황(소진율·단계·발동 신호·스트레스·MP 괴리·시장 급변 트리거)을 받아
운용역이 **1분 안에 읽는** 브리프를 쓴다. 수치는 전부 코드 것을 `[F]` 로 인용하고
새 수치를 만들지 않는다.

- `headline`: 1문장. "정상" / "경고 n건" / "축소 n건" / "중단" 중 사실에 맞는 것으로 시작.
- `interpretation`: 3줄 이내. 신호가 있으면 신호→왜 중요한지→무엇을 볼지. 신호가 없으면
  스트레스 최악 시나리오 1줄 + 괴리 상위 1~2건 + 시장 급변 여부.
- `todo`: 오늘 할 일. 발동 신호의 요구 조치·기한, 미처리 경고, 보류 중 점검 보고서.
  없으면 "특이 조치 없음".
