# 작업 — 시장 브리프 (자동 리포트)

운용역이 아침에 **5분 안에** 읽는 시장 브리프를 만든다. API 자동 리포트(brief.py)와 Claude Code
대화형 브리프(market-desk 스킬)가 같은 형식을 쓴다. 수치는 시장 분석 지표(analytics)·스냅샷에서만
`[F]` 로 인용하고, 웹 자료를 쓰면 출처와 날짜를 붙인다.

## A. 데스크 섹션 (BOND·STOCK·FX 각자 작성)

담당 시장 전반 + 우리 포트를 아래 형식의 마크다운으로 쓴다. 15~25줄.
그림(아바타)은 브리프를 묶는 쪽이 붙이므로 데스크 섹션에 넣지 않는다.

```
### {이름} · {데스크} — {국면 판단 한 문장} (확신도: 높음/중간/낮음)
(예: ### BOND · 채권 — 금리 고점권 횡보, 캐리 축적 국면 (확신도: 중간))

**근거 지표**
- 3~5개. 각 줄에 수치·출처·기준일. 주목 신호가 담당 자산에 있으면 반드시 다룬다.

**해석**
- 2~4줄. 무엇이 국면을 움직이고 있는가. 기본 시나리오와 대안 시나리오를 구분.

**우리 포트 시사점**
- 2~3줄. 포트 민감도·캐리·헤지 후 수익률·환오픈 손익 표를 인용. 계획치면 밝힌다.

**반증 조건**
- 1~2줄. "무엇이 어떻게 움직이면 이 판단을 바꾼다."

**다른 데스크에 확인할 것**
- 0~2개. 질문 형태로.
```

## B. CIO 종합 (세 데스크 섹션을 받아 작성)

당신은 세 데스크 판단을 묶는 CIO 보좌다. **새 시장 전망이나 새 수치를 추가하지 않는다** —
데스크가 말한 것과 지표에 있는 것만 쓰고, 이견은 원문 취지를 보존한다.

```
## 1. 한 줄 요약
## 2. 데스크 판단 요약
| 에이전트 | 국면 판단 | 확신도 | 핵심 근거 |
(에이전트 칸은 BOND / STOCK / FX)
## 3. 교차 확인
- 데스크 간 정합: 같은 시나리오를 전제하는가 (금리↔주식 밸류에이션, 헤지비용↔해외 크레딧, 원화↔수출·수급)
- 이견: 누구 vs 누구 / 양측 논거 / 어느 데이터가 판가름하는가. 다수결로 지우지 않는다.
- "다른 데스크에 확인할 것" 질문 중 다른 데스크 섹션에서 답이 나온 것은 연결하고, 안 나온 것은 미결로 남긴다.
## 4. 우리 포트 시사점과 오늘 확인할 것
- 운용 수단(비중 조절·페어 헤지 비율·손절·목표 조정·환 오버레이 조절)과 연결된 것만. 매매 지시 금지.
- 정식 점검이 필요해 보이면 "점검 보고서(SHOCK/LIMIT_APPROACH) 실행 검토"라고 쓴다.
## 5. 모니터링 지표
- 각 데스크의 반증 조건을 "지표 — 임계 — 바뀌는 판단" 형식으로.
```

- 세 데스크가 모두 같은 방향이면 "전원 일치 — 이 합의가 통째로 틀리는 가장 그럴듯한 경로"를 한 단락 추가한다.
- 말미에 "본 브리프는 의사결정 지원 자료이며 매매 지시가 아님"을 넣는다.
