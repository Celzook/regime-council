# 작업 — 투자 포인트 점검 보고서 (산출자 패스)

투자 포인트(신규 투자 / 6개월 주기 비중 조절 / 손실한도 접근 / 시장 급변)가 발생했다.
아래 4개 항목을 점검하고 조정안·리스크 등급·운용역 확인 항목을 쓴다.

## 입력으로 받는 것 (전부 CODE 계산 — 재계산 금지)
- 트리거 정보와 운용역 입력(신규 포지션이면 자산·금액·듀레이션·헤지비율 등)
- 손실한도 현황: 전체/자산/포지션 소진율·단계, 신규 반영 후(pro-forma) 소진율, 스트레스 표, 발동 신호, 리스크 등급 하한
- 과거 유사 국면 표(담당 자산)
- 현재 MP 와 MP 괴리표
- 시장 스냅샷 (+ 수동 입력 거시지표가 있으면)

## 4개 점검 항목
1. **손실한도 점검** — 코드 수치를 인용해 결론 1~2문장. 신규 포지션이면 "추가 전→후" 소진율과
   최악 스트레스를 반드시 쓴다. 한도 초과(축소 이상)면 조정안은 축소 방향만 가능.
2. **과거 사례 점검** — 유사 국면 표에서 2~3건을 골라 날짜·당시 특징·이후 결과·최대 역행폭을
   `[F]` 로 인용하고, 현재와의 차이를 `[E]` 로. 플래그가 있으면 `caveat` 에 그 의미를 쓴다.
   "유사 국면 n건 중 m건에서 …" 형식만 허용. "과거가 반복된다"·"확률 X%" 금지.
3. **펀더멘탈 점검** — 성장·물가·정책·신용 4축. 제공된 수치가 없으면 `now` 에 "데이터 없음"
   을 쓰고 `consistent` 는 null. 추측으로 채우지 않는다.
4. **MP 괴리 분석** — 괴리표(`[F]`)를 해석하고 밴드 이탈 버킷에 대해 조정안을 쓴다.

## 조정안 규칙
- `position_id` 는 제공된 ID. 비중·듀레이션·헤지비율은 "현재→제안" 숫자로, 금액은 억원(축소 음수).
- 조정안은 코드 하한 등급과 모순될 수 없다: HALT 면 신규 금지·전량 청산 방향, REDUCE 면 축소 방향.
- 각 조정안의 `rationale` 에는 최소 1개 `[F]` 인용(한도표·괴리표·유사국면표 중)을 포함한다.
- 아무 조정도 필요 없으면 HOLD 1건으로 명시한다.

## 리스크 등급
코드 하한(제공됨) 이상으로만 정한다. 올리는 경우 그 이유를 `headline` 또는 `operator_checks` 에 쓴다.

## 운용역 확인 항목
사람이 직접 눈으로 확인해야 하는 것만 (예: "A등급 회사채 YTD 손익 -18억 원장 대조",
"유사일 2023-10-05 사례의 적절성 판단"). 3~6개.
